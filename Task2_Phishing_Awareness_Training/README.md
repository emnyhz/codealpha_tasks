\# CodeAlpha Task 2 - Phishing Awareness Training



This project was created as part of the CodeAlpha Cyber Security Internship - Task 2.



\## Project Objective



The purpose of this project is to raise awareness about phishing attacks and help users recognize common phishing techniques used by attackers.



\## Topics Covered



\- What phishing is

\- Common types of phishing attacks

\- How to identify phishing emails

\- How to recognize fake websites and suspicious URLs

\- Social engineering techniques

\- Real-world phishing examples

\- Best practices to avoid phishing attacks

\- Interactive quiz and answers
